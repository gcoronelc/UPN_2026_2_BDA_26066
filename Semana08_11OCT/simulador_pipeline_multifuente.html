Simulador de un pipeline con fuentes heterogéneas

Cuatro fuentes con formatos distintos (CSV, API REST en JSON, base de datos SQL y XML) alimentan un mismo pipeline. Cada fuente tiene su adaptador, que traduce su estructura a un esquema común. Después se normalizan los valores, se valida entre fuentes y se carga una única tabla de destino.
